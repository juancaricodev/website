# Skill Registry — website

## User Skills (global)
Skills available at `~/.config/opencode/skills/`:

| Skill | Trigger |
|-------|---------|
| branch-pr | When creating a pull request, opening a PR, or preparing changes for review |
| customize-opencode | Use ONLY when editing opencode's own configuration |
| go-testing | When writing Go tests, using teatest, or adding test coverage |
| issue-creation | When creating a GitHub issue, reporting a bug, or requesting a feature |
| judgment-day | When user says "judgment day", "review adversarial", "dual review", "doble review" |
| sdd-apply | Implementing tasks from SDD change specs |
| sdd-archive | Archiving completed SDD changes |
| sdd-design | Creating technical design documents |
| sdd-explore | Exploring and investigating ideas before committing |
| sdd-init | Initializing SDD context in a project |
| sdd-onboard | End-to-end SDD walkthrough |
| sdd-propose | Creating SDD change proposals |
| sdd-spec | Writing SDD specifications |
| sdd-tasks | Breaking down SDD changes into implementation tasks |
| sdd-verify | Validating SDD implementation against specs |
| skill-creator | Creating new AI agent skills |
| skill-registry | Creating/updating the skill registry |

## Project Conventions
- **AGENTS.md**: Read from `~/.config/opencode/AGENTS.md` — persona, engram protocol, rules, SDD skills list
- **BEM**: CSS follows Block Element Modifier naming convention
- **Vanilla stack**: No frameworks, no build tools
- **HTML5**: Semantic HTML
- **CSS3**: Vanilla CSS with @import for component splitting
- **Deployment**: GitHub Pages with CNAME (juancarico.dev)
